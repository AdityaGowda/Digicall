## 🚀 About Digicall
Digicall is a full-stack video-calling platform where users can create accounts, connect with people, and start **one-to-one or group video calls**.  
The project is **in ongoing development**, and new features are actively being added.

## 🧑‍💻 Tech Stack

### **Frontend**
- React.js  

### **Backend**
- Node.js  
- Express.js  

### **Database**
- MySQL  

### **Video Call Integration**
- 100ms

## ⭐ Features

### 🔐 **User Authentication**
- Signup  
- Login  
- Logout  
- Secure session management  

### 🧑‍🤝‍🧑 **User Connections**
- Search users using their **Gmail ID**  
- Send connection requests  
- Accept or reject requests  
- See list of connected users  

### 🎥 **Video Calling**
- One-to-one video call  
- Group video call  
- Integrated using **100ms video SDK**  

### 📅 **Meetings**
- Create **Instant Meeting**  
- **Schedule a Meeting**  
- Add connected users to the meeting  
- Invite to meeting shows in dashboard notification tab
- View list of invited people  
- View who created the meeting

## 🚀 Getting Started

### Clone Repository
```bash
git clone https://github.com/AdityaGowda/Digicall.git
cd Digicall

cd server
npm install
node server.js

cd ../client
npm install
npm run dev
```
